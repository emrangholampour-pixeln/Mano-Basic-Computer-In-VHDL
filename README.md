این کد به زبان VHDL، پیاده‌سازی سخت‌افزاریِ کامپیوتر پایه‌ی معروف موریس مانو (Mano's Basic Computer) را در قالب یک واحد پردازشی (Entity) و ساختار رفتاری (Behavioral Architecture) انجام داده است. این ماژول رجیسترهای اصلی پردازنده مانند AC، PC، IR، SP، DR و E را مدیریت کرده و با اتصال به یک حافظه (BlockRAM)، سیکل‌های سخت‌افزاری دستورات، مدیریت وقفه‌ها (Interrupts) و اجرای دستورات پایه‌ای نظیر LDA، ADD، BUN و دستورات رجیستری/I/O را پیاده‌سازی می‌کند.
